# FREQUENCY ANALYZER
An Arduino based frequency spectrum analyzer. (Created as a university project)
<br><br>
!! WARNING !!<br>
For those who are attempting to recreate this project, be warned.
This project was NOT designed with reproducability in mind. 

### COMPONENTS USED
- 1x 16x16 WS2812B Addressable LED matrix
- 1x HW-484 Sound sensor module
- 2x NRF24L01 Transciever (one for each arduino)
- 2x Arduino Nano (One for case, one for remote)
- 1x 9V battery & connector (for remote)
- 4x push button (for remote)
- 2x LEDs (for remote)
- 3x 330 Ohm resistors (1 for LED matrix, 2 for remote LEDs)
- 3x M3 standoffs & screws (for the remote 3D printed enclosure)
- 1/8 inch laser-cuttable material, like acrylic or wood
- frosted acrylic for the front of the display (we achieved this by sanding clear acrylic)
- 3d printed bits for remote and grid for LEDs

### OTHER USEFUL STUFF
- Proto-boards for soldering onto, get the multi-pack from Amazon.
- A soldering workstation
- Solid core wire
- Hot glue, Superglue, and double sided tape would help with assembling.
